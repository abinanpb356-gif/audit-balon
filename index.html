1 Cara Menyambungkan Semua Laptop ke 1 Jaringan Wi-Fi (Offline Lokal / Tanpa Kuota)

Anda dapat menghubungkan seluruh laptop di balai desa tanpa memerlukan kuota internet, cukup dengan 1 Router Wi-Fi atau Hotspot HP dari 1 Ponsel:

Di Laptop Server (Laptop Utama):

  1. Sambungkan laptop ke Wi-Fi kantor desa atau Hotspot HP.
  2. Ekstrak berkas pilkades-2027-siap-deploy.zip.
  3. Klik 2x berkas jalankan-server-windows.bat.
  4. Jendela hitam akan muncul dan menampilkan IP laptop, contoh: http://192.168.1.15:3000.

Di Semua Laptop Operator Lain:

  1. Sambungkan laptop ke Wi-Fi / Hotspot yang sama.
  2. Buka Google Chrome atau Microsoft Edge.
  3. Ketik alamat IP laptop server tadi: http://192.168.1.15:3000.
  4. Tekan Enter. Aplikasi langsung tersambung dan deteksi ganda otomatis aktif!

3 SOP Penanganan NIK Ganda: JANGAN LANGSUNG DIGUGURKAN!

Sesuai aturan pilkades dan asas keadilan bagi seluruh calon:

Langkah 1: Klarifikasi ke Calon Terkait

Panitia memanggil calon/tim sukses yang mengajukan KTP ganda dan menanyakan secara tertutup: "Dari mana memperoleh fotokopi KTP warga ini?" Beritahukan calon bahwa Panitia akan turun menemui warga secara rahasia.

Langkah 2: Panitia Turun Langsung Secara Rahasia

Panitia membentuk tim pemeriksa lapangan yang turun langsung mendatangi rumah warga bersangkutan secara rahasia tanpa didampingi calon untuk menanyakan: "Bapak/Ibu sebenarnya secara sadar dan murni mau mendukung calon yang mana?"

Langkah 3: Input Keputusan Klarifikasi ke Aplikasi

Setelah warga memberikan jawaban, Panitia membuka aplikasi, klik tombol [Klarifikasi] pada baris NIK bersangkutan, lalu pilih calon yang murni didukung warga (otomatis disahkan/MS dan calon lawan gugur/TMS), atau pilih 'Warga Menolak Keduanya' jika KTP dicatut tanpa izin.

4 Mengatasi Kendala Jaringan (Troubleshooting & Tips)

  • Layar Laptop Operator Lain Tidak Bisa Buka Alamat IP: Pastikan di Laptop Server, saat pertama kali menjalankan server dan muncul pop-up Windows Firewall, Anda telah mencentang "Private Networks" dan klik "Allow access".
  • Cara Mengetahui IP Laptop Server Manual: Buka CMD (Command Prompt) di laptop server, ketik ipconfig, lalu cari IPv4 Address pada bagian Wireless LAN Adapter Wi-Fi (misal: 192.168.1.50).
  • Menggunakan Hotspot HP Tanpa Kuota: Cukup aktifkan Personal Hotspot di HP Android/iPhone Anda. Hubungkan semua laptop ke hotspot tersebut. Aplikasi dapat bertukar data secepat kilat tanpa memakan kuota internet!
  • Tidak Ada Batas Jumlah Laptop: Anda dapat menghubungkan 3 laptop, 5 laptop, hingga 20 laptop sekaligus tanpa hambatan.

5 Cara Menghubungkan Jika Di-deploy ke Cloudflare

Ada 2 Cara Deploy ke Cloudflare tergantung kebutuhan Anda:

Pilihan A: Menggunakan Cloudflare Pages (Hosting Web Statis)

  1. Buka dashboard dash.cloudflare.com → pilih menu Workers & Pages → Create application → Pages.
  2. Pilih Direct Upload (Upload assets) lalu upload file index.html (atau sip-pilkades-2027.html).
  3. Beri nama project (misal: pilkades-desa-2027), lalu klik Deploy Site.
  4. Setelah selesai, Anda akan mendapatkan alamat URL publik berawalan HTTPS, contoh: https://pilkades-desa-2027.pages.dev.
  5. Cara Menghubungkan Operator: Bagikan link HTTPS tersebut ke semua operator (lewat WhatsApp / grup panitia). Setiap laptop cukup membuka link tersebut di Chrome/Edge/HP di mana saja selama ada koneksi internet.

Pilihan B: Menggunakan Cloudflare Tunnel (Sync Real-Time Penuh + Gratis Domain HTTPS)

Jika Anda ingin sinkronisasi instan real-time antar semua laptop tanpa perlu sewa server cloud mahal:

  1. Jalankan jalankan-server-windows.bat di laptop server desa (berjalan di port 3000).
  2. Buka CMD dan ketik: cloudflared tunnel --url http://localhost:3000 (atau via menu Zero Trust Tunnel).
  3. Cloudflare akan langsung memberikan domain HTTPS gratis, misal: https://pilkades-cepat.trycloudflare.com.
  4. Semua operator di rumah atau di balai desa membuka link tersebut, dan data langsung tersinkronisasi 100% real-time dengan deteksi ganda otomatis!

Cadangkan & Pulihkan Data Pilkades (Anti-Hilang)

Jaminan Keamanan Data Impor & Verifikasi Dukungan

1. Unduh Berkas Cadangan Lengkap (.json)

Menyimpan seluruh Master DPS, Master Penduduk, dan Hasil Verifikasi Dukungan saat ini ke dalam 1 berkas kecil. Simpan di Flashdisk / Harddisk sebagai jaminan keamanan.

2. Pulihkan Data dari Berkas Cadangan (.json)

Jika Anda baru menyalakan ulang laptop atau ingin memindahkan data ke laptop lain, cukup pilih file cadangan .json yang telah diunduh sebelumnya.

Mengapa data sebelumnya sempat hilang saat mulai ulang?

  • Folder ZIP Belum Di-Extract: Jika Anda mengklik jalankan-server-windows.bat langsung dari dalam file ZIP tanpa di-Extract (klik kanan > Extract All), Windows menyimpannya di folder sementara (Temp) yang otomatis terhapus saat laptop mati.
  • Browser Berbeda atau Mode Samaran (Incognito): Mode samaran tidak menyimpan riwayat atau data. Pastikan selalu membuka browser Google Chrome biasa.
  • Sistem Auto-Sync Baru: Sekarang aplikasi sudah dilengkapi fitur Auto-Recovery: browser akan otomatis memulihkan data terakhir Anda secara cerdas.
